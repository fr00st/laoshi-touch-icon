Лаоши · Учебник (180-2.png)

Тест центрированного исходника 180-2.png (180×180 px с полями 40–45 px для скругления iOS Safari).

Инструкция для проверки на iPhone:
  1. Откройте страницу в Safari.
  2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх).
  3. Выберите «На экран „Домой“».
  4. Убедитесь, что превью иконки четкое, без мыла, и нажмите «Добавить».

🤖 Инструкция для агента и внедрения

1. Как скачать файл иконки

Скачать проверенный файл 180-2.png в целевой каталог сайта:

# Скачивание файла в текущую папку проекта:
curl -fsSL -o apple-touch-icon.png https://fr00st.github.io/laoshi-touch-icon/180-2.png

# Если внедрение на сервере IHC (komdev.ru/laoshi/):
# положить по пути: /opt/komdev-site/laoshi/apple-touch-icon.png

2. Код для вставки в <head>

Вставить в HTML-документ (важно: путь должен быть относительным или с точным префиксом подпапки, без ошибочного слэша от корня):

<!-- Apple Touch Icon (относительный путь + cache buster) -->
<link rel="apple-touch-icon" sizes="180x180" href="apple-touch-icon.png?v=3">
<link rel="icon" type="image/png" sizes="180x180" href="apple-touch-icon.png?v=3">

<!-- Мета-теги для закрепления на домашнем экране iOS -->
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-title" content="Лаоши">
<meta name="apple-mobile-web-app-status-bar-style" content="default">
<meta name="theme-color" content="#feda4b">

3. Как гарантированно избежать и сбросить кэш iOS

iOS Safari очень агрессивно и намертво кэширует ярлыки в системной директории WebClips. Чтобы не видеть старое «мыло»:

  • Cache Buster в URL: Всегда меняйте версию в теге (href="apple-touch-icon.png?v=3"). При смене строки запроса Safari вынужден запросить новый ассет.
  • Удалить старую иконку с экрана: Долгое нажатие на старый ярлык на айфоне → «Удалить закладку» (или «Удалить с экрана „Домой“»).
  • Сбросить данные сайта в Safari: На iPhone открыть Настройки → Safari → Дополнения → Данные сайтов → найти домен и смахнуть влево (Удалить).
  • Очистить локальный кэш вкладки: Перезагрузить страницу в Safari (удерживая значок обновления → «Перезагрузить без блокировщиков / очистить»), после чего добавить на экран заново.
